## About

**Cigarette Client** is a free Minecraft client for **Java Edition 1.21.11**. It bundles combat, inventory, utility, render and world modules into one clean package, with a HUD where every element is its own toggle, so you only see what you want.

It's free to download and use, with no paywalls. Donations are optional and help cover hosting and development.

## Features

| Category | Modules |
|----------|---------|
| **Combat** (11) | AimAssist, Aimbot, AutoClicker, Triggerbot, KillAura, Reach, HitSelect, HitSwap, Velocity, WTap, Sprint |
| **Inventory** (6) | AutoTotem, AutoArmor, AutoHotbar, InventoryFill, InventoryManager, ChestSteal |
| **Utility** (10) | Fly, BoatFly, NoFall, Parkour, Scaffold, Clutch, NoJumpDelay, FastPlace, FastUse, Freecam |
| **Render** (5) | ESP, Xray, NameTags, Radar, Fullbright |
| **World** (3) | BaseFinder, Search, AutoFish |
| **HUD** (8 toggles) | FPS, Coordinates, CPS, Clock, Compass, Keystrokes, ArmorStatus, PotionStatus |
