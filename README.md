## About

**Cigarette Client** is a free Minecraft client for **Java Edition 1.21.11**. It brings together combat, inventory, movement, render and world modules in one package, alongside a fully customizable HUD.

With **43 modules**, two interface styles, configurable settings and customizable keybinds, Cigarette Client gives you control over how you play and what you see on screen.

It's completely free to download and use, with no paywalls. Donations are optional and help cover hosting and development.

## Features

### Combat (18 modules)

| Module | Description |
|--------|-------------|
| **AimAssist** | Gently nudges your aim toward nearby targets while attacking. |
| **Aimbot** | Automatically turns your view toward the best nearby target. |
| **AutoClicker** | Clicks at a randomized CPS while your crosshair is on an entity. |
| **Triggerbot** | Automatically attacks when your crosshair is on a valid target. |
| **KillAura** | Attacks the best nearby target. Includes Auto Weapon, Legit Cam and Priority While Moving. |
| **CrystalAura** | Targets enemies, breaks and places end crystals, and places obsidian. Includes self-damage limits and a max-crystals setting. |
| **AnchorAura** | Places, charges and detonates respawn anchors. Includes a max-anchors setting and skips the Nether. |
| **BedAura** | Places and detonates beds, including beds already placed. Includes a max-beds setting. |
| **BowAura** | Automatically shoots with bows and crossbows, predicting arrow drop and target movement. |
| **AutoPearl** | Throws an ender pearl toward the landing position of an enemy's pearl. |
| **AutoMove** | Walks or sprints toward the nearest target. |
| **Reach** | Changes your client-side interaction range. |
| **HitSelect** | Cancels weak or wasted attacks. |
| **HitSwap** | Automatically switches to your best sword or axe when attacking. |
| **Velocity** | Reduces incoming knockback. |
| **WTap** | Briefly releases sprint after each hit. |
| **Sprint** | Automatically keeps you sprinting. |

### Inventory (6 modules)

| Module | Description |
|--------|-------------|
| **AutoTotem** | Automatically equips a totem in your offhand when your health is low. |
| **AutoArmor** | Equips the best armor available in your inventory. |
| **AutoHotbar** | Refills hotbar stacks when they run low. |
| **InventoryFill** | Fills empty hotbar slots using items from your inventory. |
| **InventoryManager** | Automatically discards items on your editable junk list. |
| **ChestSteal** | Shift-clicks all items out of chests you open. |

### Utility & Movement (11 modules)

| Module | Description |
|--------|-------------|
| **Fly** | Offers Velocity, Abilities and Glide modes. |
| **BoatFly** | Allows you to fly while riding a boat. |
| **NoFall** | Prevents fall damage. |
| **Parkour** | Automatically jumps at block edges. |
| **Scaffold** | Places blocks beneath you. Includes Normal and Legit styles, with Legit style walking forward while looking backward and crouching only when placing. Also fights nearby enemies. |

| **FastPlace** | Removes the block-placement delay. |

### HUD

| Element | Description |
|---------|-------------|
| **Hud** | Master switch, watermark and enabled-modules list. |
| **FPS** | Displays your current FPS. |
| **Coordinates** | Displays your current coordinates. |
| **CPS** | Displays clicks per second. |
| **Clock** | Displays the current time. |
| **Compass** | Displays your direction. |
| **Keystrokes** | Displays your pressed keys. |
| **ArmorStatus** | Displays your equipped armor status. |
| **PotionStatus** | Displays your active potion effects. |

## Interfaces

Cigarette Client includes two interface styles:

- **Vape (ClickGui):** A classic ClickGUI-style interface for managing modules.
- **Window:** A draggable, window-based interface inspired by Corz.

Choose your preferred style in the Settings screen.

## Settings & Customization

The Settings screen includes:

- **Export Config:** Export your current configuration.
- **Import Config:** Import a saved configuration.
- **Interface Style:** Switch between Vape and Window interfaces.
- **Move & Sprint While GUI Is Open:** Continue moving while using the interface.
- **Edit Thrown Items:** Customize the thrown-items list.

### Keybinds

Middle-click any module to assign or change its keybind.

## Installation

1. Download the latest version from the [official website](https://cigarette-client.vercel.app/) or the [Releases](../../releases) page.
2. Install the client using the appropriate Minecraft/Fabric installation setup.
3. Launch **Minecraft Java Edition 1.21.11**.
4. Open the client menu using **RightShift**.
